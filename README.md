Deskripsi dari Tugas Besar 1

Repositories ini berisi tentang program algoritma local search yang bertujuan untuk optimasi penempatan kendaraan dalam kapal. Steuktur repositories ini terdiri dari
1. src
   -> Berisi tentang program utama untuk menjalankan local search
2. docs
   -> Laporan dari projek ini
3. output
   -> Hasil dari local search yang dijalankan

Algoritma Hill-Climbing dapat dijalankan dengan menggunakan program:
  python hc_run.py
Setelah beberapa detik, algoritma akan mengembalikan hasil search.
